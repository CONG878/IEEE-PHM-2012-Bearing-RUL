# 예측 결과 및 해석

본 연구에서는 IEEE PHM 2012 Bearing Dataset을 대상으로 Feature Engineering, LOBO Validation, Multi-Algorithm Modeling, Rational Calibration 및 Ensemble을 적용하여 RUL을 예측하였다.

최종 Test prediction에서는 LOBO 모델별 알고리즘 선택을 적용하고, 각 모델의 prediction에 model-specific Rational Calibration을 수행한 뒤 Harmonic Ensemble으로 최종 RUL을 산출하였다.

본 문서는 이러한 최종 예측 과정에서 관찰된 성능과 각 방법의 역할을 중심으로 결과를 해석한다.

---

## 1. LOBO Validation에서의 Rational Calibration 효과

LOBO validation에서 Rational Calibration 적용 전후를 비교한 결과, 전반적인 예측 성능이 크게 개선되었다.

| Method   | RMSE (s) | MAE (s) | SMAPE (%) |     R² | PHM Score |
| -------- | -------: | ------: | --------: | -----: | --------: |
| Raw      |  2349.53 | 1809.74 |     66.57 | -0.257 |    0.1437 |
| Rational |   868.84 |  683.20 |     34.29 |  0.828 |    0.3206 |

RMSE는 약 63%, MAE는 약 62%, SMAPE는 약 32.28%p 감소했으며, R² 역시 음수에서 0.828로 개선되었다. PHM Score도 0.1437에서 0.3206으로 상승하였다.

베어링별로 보면 개선의 정도에는 차이가 있었지만, 현재 수정된 결과에서는 Rational Calibration 적용 후 **모든 LOBO validation bearing의 RMSE가 감소**하였다. 따라서 현재 validation 조건에서는 Rational Calibration에 의한 RUL scale 보정 효과가 모든 LOBO validation bearing에서 관찰되었다고 볼 수 있다.

다만 Calibration은 새로운 degradation trajectory를 학습하는 방법이 아니다. 모델이 생성한 `RUL_norm`을 pointwise monotone function으로 재매핑하여 예측값의 규모와 비선형적인 편향을 조정하는 후처리이다. 따라서 기존 prediction의 시간적 형태와 변동성을 유지하면서 RUL scale을 조정한다.

이에 따라 Rational Calibration의 역할은 **예측 trajectory 자체를 수정하는 것이 아니라, 모델 출력에 존재하는 systematic RUL scale bias를 보정하는 것**으로 해석하였다.

## 2. Test Set Baseline과 Rational Calibration 효과

Rational Calibration을 적용한 LOBO 모델들의 prediction에 Harmonic Ensemble을 수행한 결과, 모든 LOBO 모델을 Random Forest로 구성한 `All RF`가 다음과 같은 baseline을 형성하였다.

| Configuration                | RMSE (s) | MAE (s) | SMAPE (%) |     R² | PHM Score |
| ---------------------------- | -------: | ------: | --------: | -----: | --------: |
| All RF + Rational + Harmonic |  2561.62 | 1500.06 |     61.68 | 0.0521 |    0.3095 |

이 결과를 이후 LOBO별 알고리즘 선택의 기준점으로 사용하였다.

Calibration 적용 전 Harmonic Ensemble 결과와 비교하면 다음과 같다.

| Method              | RMSE (s) | MAE (s) | SMAPE (%) |     R² | PHM Score |
| ------------------- | -------: | ------: | --------: | -----: | --------: |
| Harmonic Raw        |  2931.41 | 2081.17 |     79.08 | -0.241 |    0.0773 |
| Harmonic + Rational |  2561.62 | 1500.06 |     61.68 | 0.0521 |    0.3095 |

Calibration 이후 RMSE는 약 12.6%, MAE는 약 27.9%, SMAPE는 약 22.0% 감소했고 R²도 음수에서 양수로 전환되었다.

특히 MAE와 SMAPE의 개선 폭이 RMSE보다 크다는 점은 전체적인 예측 수준의 개선이 나타난 가운데, 일부 큰 오차는 여전히 남아 있음을 시사한다.

따라서 Test set에서도 Calibration은 **전체적인 예측 수준을 조정하는 역할**에는 효과적이었지만, 개별 베어링에서 발생하는 잘못된 degradation trajectory 자체를 새롭게 학습하거나 수정한 것은 아니다.

## 3. LOBO별 Multi-Algorithm Model Selection

기존에는 모든 LOBO 모델에 동일한 알고리즘을 적용하였다. 그러나 LOBO에서는 각 모델이 서로 다른 bearing 조합으로 학습되므로, 동일한 알고리즘이 모든 LOBO 조건에서 동일하게 적합하다고 가정할 필요는 없다.

이에 따라 Stage 05에서 Random Forest와 CatBoost를 각각 독립적으로 전체 LOBO에 대해 학습하고, Stage 06에서 **LOBO 모델별로 사용할 알고리즘을 선택**할 수 있도록 구성하였다. LightGBM과 XGBoost 역시 공통 Model Factory에서 지원하지만, 이번 최종 실험에는 포함하지 않았다.

현재 LOBO 모델의 대응 관계는 다음과 같다.

| Model   | Held-out Bearing |
| ------- | ---------------- |
| Model 0 | Bearing1_1       |
| Model 1 | Bearing1_2       |
| Model 2 | Bearing2_1       |
| Model 3 | Bearing2_2       |
| Model 4 | Bearing3_1       |
| Model 5 | Bearing3_2       |

여기서 알고리즘 선택은 **개별 Test bearing에 맞춘 선택이 아니라, 해당 prediction을 생성하는 LOBO 모델 단위의 선택**이다. 즉, 특정 Test bearing의 정답에 맞추어 알고리즘을 선택하는 것이 아니라 각 LOBO 모델의 학습 조건에 따라 사용할 알고리즘을 결정한다.

이번 실험에서는 전체 모델을 RF로 유지한 상태에서 한 번에 하나의 LOBO 모델만 CatBoost로 교체하는 single-override 실험을 수행하였다.

| Configuration      |    RMSE (s) |     MAE (s) | SMAPE (%) |         R² |  PHM Score |
| ------------------ | ----------: | ----------: | --------: | ---------: | ---------: |
| All RF             |     2561.62 |     1500.06 |     61.68 |     0.0521 |     0.3095 |
| Model 0 → CatBoost | **2447.90** | **1286.02** | **57.25** | **0.1344** | **0.3596** |
| Model 1 → CatBoost |     2685.21 |     1628.45 |     63.47 |    -0.0416 |     0.2657 |
| Model 2 → CatBoost |     2624.69 |     1580.32 |     62.31 |     0.0048 |     0.2149 |
| Model 3 → CatBoost |     2566.75 |     1558.39 |     60.40 |     0.0483 |     0.1893 |
| Model 4 → CatBoost |     2628.68 |     1544.71 |     61.17 |     0.0018 |     0.2459 |
| Model 5 → CatBoost |     2631.47 | **1498.40** | **61.21** |    -0.0003 |     0.3340 |

Model 0을 CatBoost로 교체한 경우에는 RMSE, MAE, SMAPE, R² 및 PHM Score가 모두 개선되었다. 반면 다른 LOBO 모델에서는 일부 지표가 개선되더라도 다른 지표가 악화되는 등 일관된 개선이 나타나지 않았다.

따라서 이 결과를 **CatBoost가 Random Forest보다 전반적으로 우수하다**는 의미로 해석하기는 어렵다. 오히려 동일한 알고리즘을 모든 LOBO 모델에 적용하는 것보다, **LOBO 모델의 학습 조건에 따라 알고리즘의 적합성이 달라질 수 있음**을 보여주는 결과로 해석하였다.

## 4. 최종 Configuration과 Test 성능

Single-override 실험 결과를 바탕으로 최종 configuration은 다음과 같이 구성하였다.

```text
Model 0 → CatBoost
Model 1 → Random Forest
Model 2 → Random Forest
Model 3 → Random Forest
Model 4 → Random Forest
Model 5 → Random Forest
```

즉, 기본적으로 Random Forest를 활용하되 `Bearing1_1`을 held-out bearing으로 사용하는 Model 0에 대해서만 CatBoost를 선택하였다. 나머지 LOBO 모델에서는 Random Forest를 유지하였다.

각 LOBO 모델에서 선택된 알고리즘에 대응하는 Calibration parameter를 적용한 뒤 Harmonic Ensemble을 수행한 최종 Test 결과는 다음과 같다.

| Configuration                        |    RMSE (s) |     MAE (s) | SMAPE (%) |         R² |  PHM Score |
| ------------------------------------ | ----------: | ----------: | --------: | ---------: | ---------: |
| All RF baseline                      |     2561.62 |     1500.06 |     61.68 |     0.0521 |     0.3095 |
| **Final: Model 0 CB + Model 1–5 RF** | **2447.90** | **1286.02** | **57.25** | **0.1344** | **0.3596** |

All RF baseline과 비교하면 RMSE는 약 4.4%, MAE는 약 14.3%, SMAPE는 약 4.43%p 감소하였다. R²는 0.0521에서 0.1344로 증가했으며, PHM Score는 0.3095에서 0.3596으로 상승하였다.

따라서 현재 실험 조건에서는 모든 LOBO 모델에 동일한 알고리즘을 적용한 구성보다 **LOBO별 알고리즘 선택을 적용한 최종 구성이 모든 주요 평가 지표에서 개선된 결과를 보였다.**

## 5. 최종 Pipeline에서 각 방법의 역할

현재 최종 pipeline은 다음과 같이 구성된다.

```text
LOBO-specific Algorithm Selection
            ↓
       Model Prediction
            ↓
Model-specific Rational Calibration
            ↓
     Prediction Matrix
            ↓
      Harmonic Ensemble
            ↓
        Final RUL
```

각 단계는 서로 다른 역할을 수행한다.

### 5.1 LOBO-specific Algorithm Selection

LOBO 모델별로 학습 조건이 다르다는 점을 이용하여 각 모델에 적합한 알고리즘을 선택한다.

이번 실험에서는 Model 0에서 CatBoost가 선택되었고 Model 1~5에서는 Random Forest가 유지되었다. 따라서 알고리즘 선택의 역할은 **LOBO 모델별 학습 조건에 따른 알고리즘 적합성의 차이를 반영하는 것**으로 볼 수 있다.

### 5.2 Model-specific Rational Calibration

Calibration은 개별 모델의 RUL 출력 scale에 존재하는 체계적인 편향을 보정한다.

각 LOBO 모델의 Calibration parameter는 독립적으로 결정되며, 알고리즘이 다른 경우에는 해당 알고리즘에서 생성된 prediction에 대응하는 Calibration 결과를 사용한다.

따라서 Calibration은 알고리즘 선택 이후 **각 모델의 RUL 출력 scale을 보정하여 서로 다른 모델의 prediction을 Ensemble에 사용할 수 있도록 조정하는 단계**로 이해하였다.

### 5.3 Harmonic Ensemble

Harmonic Ensemble은 여러 LOBO 모델의 RUL을 산술 평균하지 않고 RUL의 역수를 평균한 뒤 다시 역수를 취한다.

$$
RUL_H =
\frac{K}{\sum_{k=1}^{K}1/RUL_k}
$$

여기서 `1/RUL`은 remaining time의 역수이며, 이를 통해 **짧은 RUL prediction에 상대적으로 큰 영향력**을 부여할 수 있다.

본 연구에서는 이를 terminal/EoL 영역의 prediction을 ensemble 결과에 보다 강하게 반영하기 위한 방식으로 활용하였다.

이러한 특성이 PHM 2012의 비대칭적인 평가 구조와 부합할 수 있다는 것과, Harmonic Ensemble이 PHM Score를 직접 최적화한다는 것은 별개의 문제이다. 또한 잘못된 low-RUL prediction 역시 상대적으로 크게 반영할 수 있으므로, short-RUL을 강조하는 특성은 동시에 하나의 trade-off를 갖는다.

## 6. PHM Score에서 나타나는 베어링별 성능 기여의 차이

최종 Test 결과에서 일반적인 회귀지표와 PHM Score는 서로 다른 평가 관점을 제공한다.

최종 구성의 RMSE는 2447.90초, MAE는 1286.02초, SMAPE는 57.25%이며 R²는 0.1344이다. 반면 PHM Score는 0.3596을 기록하였다.

이러한 차이는 PHM 2012의 scoring function이 단순한 평균 오차가 아니라 **과대추정과 과소추정을 비대칭적으로 평가하고 오차 크기에 따라 지수적인 penalty를 적용하는 구조**를 갖기 때문이다.

따라서 동일한 prediction에서도 베어링별 오차가 전체 Score에 기여하는 정도는 동일하지 않다. 상대적으로 큰 오차가 발생한 베어링은 Score에 대한 기여가 제한될 수 있으며, 반대로 상대적으로 정확한 prediction은 전체 Score에 더 큰 영향을 줄 수 있다.

따라서 일반 회귀지표와 PHM Score가 서로 다른 모습을 보이는 것은 평가 오류라기보다 **서로 다른 목적을 가진 평가 함수가 동일한 prediction을 서로 다른 관점에서 평가한 결과**로 이해하는 것이 적절하다.

이 현상을 특정 베어링에 대한 모델의 의도적인 포기나 제외로 해석할 필요도 없다. 이는 PHM Score의 비대칭적인 평가 구조에서 발생하는 **베어링별 성능 기여도의 차이**로 보는 것이 적절하다.

## 7. IEEE PHM 2012 공개 결과와의 비교

본 프로젝트의 Test set은 IEEE PHM 2012 Challenge의 공식 Test bearing 11개를 대상으로 하며, 공식 Challenge와 동일한 scoring rule을 사용하여 PHM Score를 계산하였다.

현재 최종 configuration의 PHM Score는 **0.3596**이다.

A.L.D.의 Sergey Porotsky가 보고한 overall score는 **0.25**였으며, GE Global Research의 Tianyi Wang은 **0.0981**을 보고하였다. 공식 Challenge Details에서는 이들이 당시 Industrial 부문의 주요 참가자로 기록되어 있다.

다만 이러한 수치는 2012년 당시 실제 competition 참가 방법과 당시 사용 가능한 정보 및 실험 절차를 기반으로 한 역사적 결과이다. 본 프로젝트의 LOBO Validation, Feature Engineering, Calibration, LOBO별 Algorithm Selection 및 Ensemble pipeline과 실험 조건이 동일하지 않으므로 이를 직접적인 순위 비교로 해석해서는 안 된다.

따라서 본 연구의 PHM Score 0.3596은 **2012년 competition의 순위를 재현했다는 의미가 아니라, 동일한 공식 Test set과 scoring rule에서 얻어진 결과를 역사적으로 공개된 수치와 비교할 수 있는 reference**로 보는 것이 적절하다.

## 8. 종합 해석

이번 연구의 최종 결과는 하나의 기법이 RUL prediction의 모든 문제를 해결했다는 형태보다는, **서로 다른 층위의 문제를 서로 다른 방법으로 처리한 결과**로 이해하는 것이 적절하다.

첫째, **LOBO-specific Algorithm Selection**은 각각의 LOBO 모델이 서로 다른 학습 조건을 갖는다는 점을 활용하여 모델별 알고리즘 적합성을 반영하였다.

둘째, **Rational Calibration**은 개별 모델이 생성한 RUL의 scale bias를 보정하였다. 이는 새로운 degradation trajectory를 생성하는 과정이 아니라 기존 prediction의 규모를 조정하는 후처리이다.

셋째, **Harmonic Ensemble**은 보정된 여러 LOBO prediction을 결합하면서 short-RUL prediction에 상대적으로 큰 영향력을 부여하였다. 이를 통해 terminal/EoL 영역의 판단을 ensemble 결과에 보다 강하게 반영하였다.

최종적으로 적용된 구성은 다음과 같다.

```text
LOBO-specific Algorithm Selection
    ├── Model 0 : CatBoost
    └── Model 1~5 : Random Forest
              ↓
     Model-specific Rational Calibration
              ↓
       Harmonic Ensemble
              ↓
       Final Test RUL
```

그 결과 최종 Test set에서 **RMSE 2447.90 s, MAE 1286.02 s, SMAPE 57.25%, R² 0.1344, PHM Score 0.3596**을 얻었다. 이는 All RF baseline의 PHM Score 0.3095보다 높은 값이다.

이번 결과는 **현재의 Feature, Model, Calibration 및 Ensemble 설계 범위에서 LOBO별 알고리즘 선택을 추가한 구성이 전체 동일 알고리즘 구성보다 개선된 결과를 보였음**을 보여준다.

최종 성능은 특정 하나의 기법에 의해 결정된 결과라기보다 **LOBO별 모델 선택, model-specific Calibration, 그리고 Ensemble을 순차적으로 결합한 pipeline의 결과**로 해석하는 것이 적절하다.

동시에 일반적인 RUL 오차 지표와 PHM Score는 서로 다른 평가 관점을 제공하므로, 최종 성능은 단일 지표만으로 해석하기보다 **일반적인 RUL 오차 지표와 IEEE PHM 2012의 비대칭적인 공식 평가를 함께 고려하여 해석하는 것이 적절하다.**
